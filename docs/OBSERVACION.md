# Guion de observación

Sirve para decidir si la primera clase funcionó. Tiene tres partes: probar un equipo escolar, observar la clase y comprobar la reapertura.

**El repositorio es público.** Anota en papel o en un documento privado, sin nombres de estudiantes ni fotos en las que se les reconozca. Usa números: *estudiante 1*, *estudiante 2*.

## Decisión

El objetivo es este: **una docente da una clase de 45 minutos, cada estudiante completa una misión, la guarda y en la clase siguiente la reabre en una computadora compartida, sin ayuda de un desarrollador.**

Con esos datos se decide si `arcade` pasa a ser la rama por defecto o si antes hay que corregir algo. Cada problema que se repita en más de un estudiante se registra como arreglo para el producto, la misión o esta guía.
