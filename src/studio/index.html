    Usar bloques con el teclado

    Tab entra o sale del editor. Con un bloque enfocado, T abre la caja de herramientas y W vuelve al programa. Usa flechas para navegar y Enter para elegir o editar.         Firmware y placa micro:bit

        Los bloques generan el código TypeScript del firmware. El documento TypeScript se conserva como programa independiente. Ejecutar usa el modo seleccionado; compilar prepara firmware sin iniciar la simulación.

        Sin firmware compilado
        Leer Static TypeScript del dispositivo

        Antes de ejecutar, predice con tu docente qué LED cambiará y qué hará el sprite al pulsar A o B. Después compara la placa simulada con la escena.

        En la ejecución conjunta, los botones envían los mensajes microbit-A, microbit-B y microbit-AB a los bloques «al recibir». El puente funciona en este simulador. El HEX autónomo conserva LEDs y botones; controlar una placa conectada requiere otro contrato.

        La transferencia USB abre una página propia y exige conectar y seleccionar la placa. La simulación y un HEX válido no certifican una prueba física.
