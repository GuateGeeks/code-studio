# Proposal

## Why

Web es el último contexto con una composición anterior al editor integrado E4. Principiantes con docente necesitan modificar el programa, interactuar con su resultado y consultar componentes o código en una misma estación.

## What Changes

- Programa web en bloques o en el único editor JavaScript/Python independiente del shell, junto al resultado interactivo existente.
- Ejecutar y Detener en el transporte común, con preparación y estados reales.
- Consulta «Componentes web» del estado inicial y «Código web» con fuente derivada de solo lectura, copias explícitas y exportación autónoma.
- Escritorio con dos columnas; flujo de documento y retorno/Stop en estrecho y zoom. Ayuda breve para predecir, enviar un formulario y comparar con el docente.
- Pruebas nativas de edición, formulario/lista, propiedades válidas e inválidas, foco, geometría, copias, Stop, reapertura y regresión de los demás contextos.

## Capabilities

### New Capabilities

- `integrated-web-workspace`: composición integrada de programa, resultado interactivo y consulta web con continuidad de autoría.

### Modified Capabilities

Ninguna especificación consolidada; los cambios anteriores conservan sus contratos y evidencia.

## Impact

Shell HTML/CSS, composición contextual y UI compartida 3D/web, inventario de impacto, pruebas y documentación. Se preservan los componentes declarativos, operaciones, modelos, motores, documentos, seis orígenes, GGPROJ y offline. No se añade HTML/CSS libre, framework, dependencia, formato, tutor remoto ni integración Sócrates. La validación docente y física sigue separada.
