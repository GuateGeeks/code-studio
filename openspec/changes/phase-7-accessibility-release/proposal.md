# F7 · Accesibilidad y distribución abierta

## Why
F6 amplía la autoría, pero siguen pendientes navegación por teclado, foco y una distribución con fuente y procedencia verificables. Este corte implementa el software de F7 sin atribuir pruebas de WSL a equipos escolares ni sustituir un piloto humano.

## What Changes
- Corregir salida del canvas y activación semántica de objetos; conservar foco y borradores contextuales.
- Documentar y probar teclado Blockly existente y zoom real 200/400 %.
- Adoptar AGPL-3.0-only para el código propio integrado; conservar licencias y avisos de componentes y recursos.
- Generar fuente, SBOM, notices, hashes y recetas deterministas; probar reconstrucción en dos raíces de fuentes con herramientas e insumos fijados.
- Medir arranque, heaps de alcance explícito, diez ciclos Run/Stop y sonda nativa de 100 sprites sin sobrescribir evidencia F0.
- Publicar guías de docente/contribución, compatibilidad y pendientes externos. No se añade API académica sin necesidad concreta.

## Impact
Afecta adaptador Scratch/UI, build y distribución propios; no modifica motores upstream, GGPROJ, permisos de proyectos ni CSP. Validaciones físicas, humanas y de aula permanecen pendientes de evidencia externa.
